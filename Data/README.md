# 지하철 그래프 데이터

수도권 지하철 **역 782개, 간선 1,516개, 환승 1,110개, 간선별 시간대 혼잡도.**
[`../collect/`](../collect/)의 코드로 서울교통공사 최단경로 API(`getShtrmPath2`)를 호출  
→ JSON 저장  
→ 필요한 데이터만 CSV로 정리했다.  
혼잡도는 공개된 실측 통계(간선의 41%)를 붙이고, 나머지는 실측 평균으로 생성했다.


| 파일 | 내용 |
|---|---|
| `Station/stations.csv` | 역 (그래프의 점) |
| `Edge/edges.csv` | 같은 노선 위 이웃 역 사이 이동 (그래프의 선) |
| `Transfer/transfers.csv` | 같은 역 안에서 노선 갈아타기 |
| `Congestion/congestion.csv` | 간선 × 요일별 30분 단위 혼잡도 (%) |
| `Congestion/generated_basis.csv` | 생성 혼잡도의 근거 (그룹별 실측 평균) |
| `Edge/json/`, `Transfer/json/` | API 원본 응답 (`manifest.json`에 파일 목록과 상태) |
| `Congestion/raw/` | 혼잡도 원본 xlsx (서울교통공사 1~8호선, 9호선) |

## CSV 파일 정보

### Station/stations.csv

- **station_code**: API 역코드. 역의 고유 ID이며 다른 CSV는 모두 이 코드로 역을 가리킨다
- **station_no**: 노선도에 적힌 역번호 (예: 서울역 1호선 133)
- **name**: 역 이름
- **line**: 노선명 (예: 경의중앙선)
- **api_line**: API의 노선명 (예: 경의선)
- **branch**: 지선 (본선, 경인선, 마천선 등. 여러 개면 `/`로 구분)

> 같은 이름이어도 노선이 다르면 다른 역이다. 서울역은 1호선·4호선·경의중앙선·공항철도에 하나씩 4행이다.

### Edge/edges.csv

- **line**: 노선명
- **branch**: 지선
- **from_code**: 출발역 코드
- **from_name**: 출발역 이름
- **to_code**: 도착역 코드
- **to_name**: 도착역 이름
- **seconds**: 열차 소요시간 (초)
- **meters**: 거리 (미터). 빈칸이면 API가 거리를 주지 않은 구간
- **note**: 비어 있으면 API 원본, `fix:`로 시작하면 보정한 값

> 방향이 있다. A→B와 B→A가 각각 한 행이다. 6호선 응암순환만 한 방향으로 운행한다.

### Transfer/transfers.csv

- **from_code**: 내리는 역 코드 (A호선)
- **from_name**: 내리는 역 이름
- **from_line**: A호선
- **from_prev_code**: A호선에서 직전에 지나온 역 코드 (= A호선 진행 방향)
- **from_prev_name**: 직전 역 이름
- **from_dir**: A호선 방향 표기 (상행/하행/내선/외선, 참고용)
- **to_code**: 타는 역 코드 (B호선)
- **to_name**: 타는 역 이름
- **to_line**: B호선
- **to_next_code**: B호선에서 다음에 갈 역 코드 (= B호선 진행 방향)
- **to_next_name**: 다음 역 이름
- **to_dir**: B호선 방향 표기 (참고용)
- **seconds**: 환승 걷는 시간 (초). 열차 대기시간은 시각마다 달라서 넣지 않음
- **meters**: 환승 거리 (미터)
- **note**: 비어 있으면 API 원본, `fix:`로 시작하면 보정한 값

> 한 행 예시: "수서에서 오는 3호선을 타고 가락시장에서 내려, 8호선 송파 방향 열차를 탄다. 122초."
> 같은 역·같은 노선 쌍이라도 승강장 위치에 따라 시간이 다르다 (예: 교대 2→3호선 57~158초).
> 경로 탐색 시 상태를 "(현재 역, 직전 역)"으로 두어야 이 값을 쓸 수 있다.

### Congestion/congestion.csv

- **line**: 노선명
- **branch**: 지선
- **from_code**: 출발역 코드 (`edges.csv`와 같은 간선을 가리킨다)
- **from_name**: 출발역 이름
- **to_code**: 도착역 코드
- **to_name**: 도착역 이름
- **day**: 요일 (평일 / 토요일 / 일요일)
- **source**: `measured`(서울교통공사 실측), `measured-9`(9호선 실측), `generated`(생성)
- **05:30 ~ 00:30**: 그 시각부터 30분간 이 간선을 지나는 열차의 평균 혼잡도 (%). 빈칸이면 운행 없음

> 간선 하나가 요일별로 3행, 총 4,548행이다.
> 혼잡도 = 정원 대비 승차 인원. 100%는 정원만큼, 34%는 좌석이 다 찬 정도다 (서울교통공사 기준).
> 실측의 "역 + 방향" 값은 그 역을 **출발하는** 열차의 값이라 `그 역 → 다음 역` 간선에 붙였다.

### Congestion/generated_basis.csv

- **direction**: 도심행(도착역이 3도심에 더 가까움) / 도심발
- **min_from**: 3도심까지 거리 구간 시작 (분)
- **min_to**: 구간 끝 (분). 빈칸이면 그 이상 전부
- **day**: 요일
- **n_edges**: 평균에 쓴 실측 간선 수
- **05:30 ~ 00:30**: 그 그룹 실측 간선들의 평균 혼잡도 (%)

## Choo가 보정한 데이터

API 원본의 오류·누락을 사람이 고친 값. 각 CSV의 `note` 컬럼에 표시돼 있다 (혼잡도는 `source` 컬럼).

### stations.csv
- 보정 없음 (API 값 그대로)

### edges.csv
- **5호선 강동↔둔촌동** (`fix:branch-merge`): API가 분기점에 다른 지선 역을 끼워 넣음 → 합쳐서 140초 / 150초
- **인천2호선 독정→검암** (`fix:timetable`): 84,873초(시각 오류) → 시간표 기준 120초
- **한쪽 방향만 있던 간선 7개** (`fix:mirror`): 반대 방향 값 복사 (금천구청→광명, 개화산→방화, 김포공항→개화산, 거여→마천, 운천→임진강, 문산→운천, 가좌→신촌)
- **거리 0m 간선**: 0 → 빈칸 (API가 거리를 주지 않은 구간)

### transfers.csv
- **36행** (`fix:mirror`): API가 일부 방향 조합만 줌 → 반대로 걷는 값으로 채움 (API 데이터에서 93% 일치하는 관계)
- **2행, 고잔** (`fix:pair-mean`): 반대 값도 없음 → 같은 노선 쌍의 평균
- **10행, 서울역 경의중앙선** (`fix:manual`): API에 경로 없음 → 네이버 지도 확인값 입력 (1호선 60초, 4호선 60초, 공항철도 240초, 2026-10-29)

### congestion.csv
`source` 열로 구분한다. 실측 617개 간선(41%), 생성 899개 간선(59%).
- **실측 원본**: 서울교통공사 지하철혼잡도정보(2026-09-30 공개, 1~8호선 서울교통공사 구간, 평일/토/일), 9호선 역별 시간별 혼잡도(2026-07-06~07-31, 평일/휴일)
- **실측 가공**
  - 0 → 빈칸 (운행 없음)
  - 9호선 휴일 값 → 토요일·일요일에 똑같이 복사
  - 9호선 급행 → 쓰지 않음 (일반 열차만)
  - 지선 분기점 특수행 6개(성수E, 응암S 등) → 해당 지선 간선에 직접 매핑
- **생성 공식** (`generated`)
  1. 각 역에서 3도심(시청·강남·여의도, 서울시 도시기본계획)까지 최단 소요시간을 구한다 (간선 + 환승 시간)
  2. 간선을 (출발역 거리 5분 구간) × (도심행/도심발)로 묶는다. 실측 간선이 20개 미만인 구간은 안쪽 구간과 합친다
  3. 생성값 = 같은 그룹 실측 간선들의 요일·시간칸별 평균 (`generated_basis.csv`)
- **오차**: 실측 노선 하나씩 숨기고 생성했을 때 MAE 11.6%p, 편향 -0.3%p, 오차 10%p 이내 56%. 그룹 없이 전체 실측 평균을 넣으면 12.4%p
- **한계**
  - 특정 구간만 유독 붐비는 병목(예: 7호선 철산→가산디지털단지 평일 08:00 실측 145%)은 평균으로 낮게 나온다
  - 실측은 도심에서 최대 38.5분까지만 있다. 그보다 먼 간선은 가장 바깥 그룹(도심행 25분+, 도심발 20분+) 값을 받는다
  - 노선별 열차 크기(경전철 2~3칸 등) 차이는 반영하지 않는다

## ETC

- **GTX-A는 제외했다.** API에서 다른 노선과의 환승이 하나도 잡히지 않는다.
- **서해선은 대곡~원시다.** 일산~곡산 공용 구간은 API에 경의선으로만 있다.
- **동명이역은 환승이 아니다.** 신촌(2호선 / 경의중앙선), 양평(5호선 / 경의중앙선)은 서로 다른 역이다.
- **역명은 API 표기를 따른다.** 4호선 `총신대입구` = 7호선 `이수` (같은 역, 환승 있음), `4·19민주묘지`, `시청.용인대`, `전대.에버랜드`.
- **인천1호선 검단호수공원·신검단중앙·아라는 `station_no`가 빈칸이다.** API가 신규 연장 구간 역번호를 아직 주지 않는다 (역코드·간선은 정상).
