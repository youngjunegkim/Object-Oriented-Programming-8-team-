# Congestion_II (실험 버전)

`../Congestion/`의 생성 공식에 **역별 이용객 차이**를 더한 버전.
실측 부분은 같고, 생성값만 간선마다 달라진다 (평일 생성 패턴 11종류 → 615종류).
오차는 11.6%p → 11.2%p로 조금 줄었다. `python build.py`로 다시 만든다.

| 파일 | 내용 |
|---|---|
| `congestion.csv` | 혼잡도. 열 구성은 `../Congestion/congestion.csv`와 같다 |
| `activity_ratio.csv` | 간선 × 요일 × 시간별 조정 비율 (생성값 = 그룹 평균 × 비율^α) |
| `raw/` | 승하차 인원 원본 (2026-09) |
| `build.py` | 생성 스크립트. 실측 매핑과 그룹 공식은 `collect/build_congestion.py`를 가져다 쓴다 |

---

## CSV 파일 정보

### activity_ratio.csv

- **line**: 노선명
- **from_code**: 출발역 코드
- **from_name**: 출발역 이름
- **to_code**: 도착역 코드
- **to_name**: 도착역 이름
- **day**: 요일 (평일 / 토요일 / 일요일)
- **05시 ~ 00시**: 조정 비율. 1이면 그룹 평균 그대로, 2이면 이용객이 그룹 기하평균의 2배

---

## 생성 공식

```
생성값[간선, 요일, 30분칸] = 그룹 평균 × 비율 ^ α
비율 = 간선 이용객 지수 / 같은 그룹 실측 간선들의 지수 기하평균
```

1. **그룹 평균**: `../Congestion/generated_basis.csv` 그대로 (3도심 거리 5분 구간 × 도심행/도심발, 실측 평균)
2. **이용객 지수**: 간선 양 끝 역의 그 시(時) 승차+하차 인원 평균
   - 환승으로 이어진 역은 하나로 합친다 (예: 서울역 = 1·4호선, 경의중앙선, 공항철도 개찰구 합계)
   - 시간대 분포는 B1(월 합계), 요일별 하루 총량은 B2(일별)로 나눈다. 추석 연휴(9/24~26)는 일요일로 본다
   - 30분 칸은 그 칸이 속한 시의 값을 쓴다
3. **α = 0.2**: 0~1을 0.05 간격으로 시험해 교차검증 오차가 가장 작은 값
4. **조정 대상**: 자기 노선 역의 절반 이상이 승하차 자료에 있는 노선만
   - 제외: 신분당선, 서해선, 김포골드라인, 용인에버라인, 의정부경전철, 인천1·2호선 → 그룹 평균 그대로
   - 이유: 신분당선 판교의 지수가 경강선 개찰구 인원만으로 잡히는 왜곡을 막기 위함

## 결과

| | `../Congestion/` | `Congestion_II` |
|---|---|---|
| 교차검증 MAE | 11.6%p | 11.2%p |
| 오차 10%p 이내 | 55.5% | 56.7% |
| 생성값 표준편차 | 10.8 | 11.2 |
| 생성값 최대 | 88.0% | 117.4% |
| 평일 생성 패턴 | 11종류 | 615종류 |

- 생성 간선 899개 중 625개가 조정됐다
- 가장 높게 오른 곳: 1호선 독산→가산디지털단지 평일 08:00 (88.0 → 117.4%)

## 한계

- α가 0.2로 작다. 역 이용객은 "그 구간 열차가 얼마나 찼는지"와 약하게만 연결된다 (통과 승객이 안 보임)
- 병목 구간은 여전히 낮게 나온다. 환승 승객은 개찰구를 지나지 않아 승하차 자료에 없다
- 승하차 자료가 월 단위라 평일·주말의 시간대 분포 차이(주말에는 출근 피크가 없음 등)는 반영하지 못한다
